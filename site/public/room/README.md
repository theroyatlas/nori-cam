# Nori's room assets

- `sprites/nori-*.png`: Nori's look, made by the author with ChatGPT image generation (2026-10-28 expressions, 2026-10-29 actions, 2026-11-01 24 more actions), background removed by the manager's script (tools/cut-nori-sprites-alpha-20261101.py in the management folder). Nori itself is never redrawn by a model on this page.
- `bg-night.jpg`, `bg-day.jpg`: the empty room, drawn by Meta `muse-image-1.0` with the author's sheets as style reference (the day version uses the night room as reference so the layout matches).
- `desktop.jpg` (Nori's computer screen) and `react.jpg` (surprised at the laptop): Meta `muse-image-1.0` with the author's sheets as reference, chosen by the author on 2026-11-01.
- `manifest.json`: sizes of every file here.
